# Attribution and source boundaries

The readout board, docking station, original fixtures, firmware and upstream
host package are **Biocoin** by the BioEE Group, University of California San
Diego; contributors named upstream include Tyler Hack, Risab Sankar and Drew
A. Hall. They are not represented as newly invented by this project.

- Repository: https://github.com/ProfDrewHall/Biocoin
- Pinned source: f723798118bb4f4d152acadf828b9ed18f3ca884
- Paper: Hack T, Hall DA. Biocoin: an open-source wearable platform for
  multiplexed and multimodal biosensing. npj Biosensing 3,44 (2026).
  https://doi.org/10.1038/s44328-026-00103-z
- Hardware and fixtures: CERN-OHL-W-2.0 per upstream notice.
- Firmware/software: MIT per upstream notice, subject to embedded notices.

`vendor/biocoin/` is an unchanged snapshot with nonessential editor settings,
debug/release binaries and printer-session files omitted. A manifest records
every included original byte stream. The original README and license notice
are included. No endorsement by the authors is implied.

The original A0 electrode geometry, flange/case/pad CAD, Resilient calibration
core, BLE bridge, verification scripts and integration documents are new work.
Electrode-process descriptions are proposals informed by linked studies; they
are not a completed or experimentally replicated fabrication recipe.

Dexcom and Libre are reference products in the source catalog. Their sensor
chemistry, proprietary manufacturing files and brands are not being released
under this project's licenses. Linked public code has the specific license and
compatibility limits documented in the catalog. Unverified-license projects are
links only and have not been vendored.
